## ✧˖° Overview

This portfolio is a **fully animated, interactive 3D web experience**, crafted to showcase my frontend skillset and bring a clean, minimal aesthetic to life. Powered by React and bundled with Vite, it integrates smooth motion effects with GSAP, section navigation, and 3D visuals via Three.js.

---

## ✧˖° Features

- 🌀 **Animated 3D Intro** with Three.js hero scene  
- ☁️ **Scroll-triggered animations** powered by GSAP for seamless transitions  
- 🧭 **Multi-page setup** using React Router (Home, About, Projects)  
- 💻 **Modern utility styling** with Tailwind CSS  
- ⚡ **Fast build & HMR** courtesy of Vite
